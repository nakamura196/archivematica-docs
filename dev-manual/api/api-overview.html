APIの概要¶

Archivematicaは、以下のRESTスタイルのAPIでサービスとリソースを公開しています：

  • Archivematica API

  • Storage Service API

ArchivematicaおよびStorage Service APIは、カスタムソリューションの作成を支援するように設計されています。

Archivematica API¶

Archivematica APIでは、以下のことが可能です：

  • 基本的なワークフロー機能をカバー（例：決定待ちのワークフロータスクのリストアップと承認）。

  • Storage Serviceへのプロキシサポート。

  • ユニットのステータスや処理設定の詳細を公開。

Archivematica APIのエンドポイントは認証が必要です。詳しくは、 認証 を参照してください。

Archivematica APIエンドポイントについては、 Archivematica API を参照してください。

Storage Service API¶

システム構成にArchivematica Storage Serviceが含まれている場合、Storage Service APIは、以下のリソースの情報を取得するのに役立ちます：

  • Pipeline

  • Space

  • Location

Storage ServiceAPIエンドポイントは、認証を必要とします。詳細は、 認証 を参照してください。

Storage ServiceAPIエンドポイントについては、 Storage Service API を参照してください。

認証¶

APIエンドポイントへのすべての呼び出しには、ユーザー名とAPIキーによる認証が必要です。

Archivematica Dashboardは、Django認証フレームワークを使用したシンプルなクッキーベースのユーザー認証システムを提供しています。認証されたユーザーのみがデータにアクセスできます。

Archivematica APIもStorage Service APIも、デフォルトではGETパラメーターを使用し、認証されたユーザーにアクセスを許可します。

GETパラメーターを設定する場合のフォーマットは::です

?username=<username>&api_key=<api_key>

APIキー値をヘッダーの一部として渡す場合、フォーマットは::になります

Authorization: ApiKey <username>:<api_key>

トランスポートレイヤーセキュリティ（TLS）プロトコルは、クライアントとサーバー間で送信されるすべてのデータが安全なアルゴリズムで暗号化され、第三者が閲覧できないようにするため、ウェブサーバー（通常はNginx）で有効にするべきです。

ユーザーのAPIキーを生成¶

APIキーは、ユーザーアカウントに関連付けられており、Dashboard Administrationタブで管理できます。Archivematicaユーザーは、管理者と非管理者の2津のカテゴリに分かれます。 ユーザー の管理者は、ユーザーアカウントの作成と編集ができます。管理者は、データベース内の任意のユーザーアカウントのAPIキーを生成もできます。

Archivematicaの既存ユーザーのAPIキーを生成するには：

  1. Admin > Users に移動し、Usersページにアクセスします。

  2. APIキーを生成したいユーザーのユーザー名を選択します。

  3. Regenerate API key ボックスをクリックします。

  4. Save をクリックします。

  5. ユーザー名をクリックして、そのユーザーのプロファイルから新しいAPIキーにアクセスします。

注釈

Storage Serviceでは、新規ユーザーごとにAPIキーが自動的に生成されます。指定したユーザーのパスワードを変更すると、そのユーザー用に新しいAPIキーがランダムに生成されます。

リクエストでAPIキーを使用¶

APIキー値は、APIエンドポイントへの各リクエストで渡されなければなりません。以下は、 cURL を使用して、ヘッダーにAPIキーを指定してリクエストを送信する例です。

リクエスト例 （curlを使用）:

curl -X GET \
https://sandbox.archivematica.org/api/transfer/completed/ \
-H 'Authorization: ApiKey admin:90e458ded261c7a5'

リクエストヘッダの例

GET /api/transfer/completed/? HTTP/1.1
Host: sandbox.archivematica.org
Authorization: ApiKey admin:90e458ded261c7a5

レスポンスヘッダの例

HTTP/1.1 200
status: 200
Server: nginx
Date: Fri, 19 Jul 2019 02:26:54 GMT
Content-Type: application/json
Transfer-Encoding: chunked
Connection: keep-alive
Vary: Accept-Language, Cookie
Content-Language: en
